# Timeline

Frises chronologiques personnalisées pour Obsidian, basées sur Dataview.

L'affichage commun se trouve dans `Histoire/Frise Chronologique.md`.
Le sélecteur en haut de la note permet de choisir les données de
`Chronologie` (civilisations) ou de `Chronologie2` (histoire de France),
puis le bouton **Afficher cette frise** charge la sélection.
